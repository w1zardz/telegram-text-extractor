# Telegram Text Extractor — копировать текст из закрытых Telegram-каналов

> **Расширение для браузера, которое позволяет скопировать текст из Telegram-канала или группы в Telegram Web — даже если автор канала включил «Запретить сохранение контента».** Поддерживает `web.telegram.org/k/` и `/a/`. Копирование постов, автосбор истории, поиск, экспорт в `.txt` / `.json`. **Manifest V3.** Никакие данные не уходят с компьютера.

## Что решает

В Telegram есть настройка канала **«Запретить сохранение контента»** (`Restrict saving content`). Когда она включена:

- в канале нельзя выделить текст,
- из контекстного меню пропадает пункт «Копировать»,
- `Ctrl+C` / `Cmd+C` не работают,
- сообщения нельзя пересылать в другие чаты.

Запрет реализован **на стороне клиента** в UI Telegram Web — текст всё ещё лежит в DOM страницы, просто интерфейс не даёт его выделить. Расширение читает текст напрямую из DOM, выводит его в собственную панель (где выделение не заблокировано) и даёт нормальную кнопку «Скопировать».

## Возможности

- 📋 Копирование текста из защищённых от копирования каналов и групп
- ▲ **Автосбор истории канала** — панель листает чат вверх и сохраняет загруженные посты (можно ограничить датой «until»)
- 🧠 Накопление: Telegram выкидывает из DOM старые посты при скролле — расширение их помнит (хранилище на чат, переживает перезагрузку)
- 🔎 Поиск, фильтр по длине, отсев повторов, копирование по дням и месяцам
- 💾 Экспорт в `.json`: числовой ID сообщения, дата, время, дословный текст, ссылка на исходный пост, ссылки внутри текста и признак пересылки из DOM
- 🌐 Сбор работает прямо в `/k/` и `/a/`; переносить чат в другой клиент не нужно
- 📜 Массовое копирование накопленных сообщений с текущими фильтрами
- 💾 Экспорт в `.txt` с временной меткой в имени файла, UTF-8
- 🎯 Кнопка «→ Jump» — перейти к исходному сообщению в чате
- 🔄 Авто-обновление при прокрутке (Telegram грузит сообщения по мере скролла — панель подхватывает их сама)
- 🌐 Telegram Web K и A; `/z/` и legacy не поддерживаются
- 🛡️ 100% локально — никаких сетевых запросов, аналитики, телеметрии, удалённой конфигурации
- 🪶 Без зависимостей и без сборки — vanilla JS
- 🌗 Тёмная панель, совместимая с темой Telegram
- ⚡ Manifest V3 — Chrome / Edge / Brave / Opera / Vivaldi / Arc

## Установка

1. Скачай репозиторий: `git clone https://github.com/w1zardz/telegram-text-extractor.git` (или ZIP-ом).
2. Открой `chrome://extensions` (или `edge://extensions`, `brave://extensions`).
3. Включи **Режим разработчика** в правом верхнем углу.
4. Жми **Загрузить распакованное расширение** и выбери папку `telegram-text-extractor`.
5. Открой [web.telegram.org](https://web.telegram.org) — внизу справа появится круглая кнопка **📋**.

После обновления распакованного расширения нажми **Обновить / Reload** в `chrome://extensions`, затем перезагрузи вкладку Telegram. K и A могут требовать отдельного входа. Расширение не читает и не переносит сессии — войди и открой канал в выбранном клиенте.

### Firefox

Для Firefox пока используй userscript-фолбэк: [`docs/userscript.user.js`](docs/userscript.user.js) с Tampermonkey или Violentmonkey.

## Как пользоваться

1. Открой нужный канал/группу на `web.telegram.org`.
2. Прокрути до постов, которые нужно скопировать (Telegram рендерит только видимые сообщения — старые подгружаются по мере скролла).
3. Нажми **📋** в правом нижнем углу — выедет панель.
4. Жми **↻** для сканирования. Дальше:
   - **📋 Copy** — скопировать один пост,
   - **Copy** — скопировать накопленные посты с текущими фильтрами,
   - **⬇ .txt** / **⬇ .json** — скачать накопленные посты с текущими фильтрами,
   - **▲ Auto-collect** — листать историю автоматически; **■ Stop** останавливает сбор.

Ручной скролл с открытой панелью тоже сохраняет появляющиеся посты. Автосбор останавливается, когда несколько попыток подряд не загрузили более старые сообщения. Это не доказывает полноту выгрузки: после сбоя соединения повтори сбор. Поле `until` проверяет самое старое сообщение в загруженной истории, а не даты в кэше. Нераспознанная дата на этой границе останавливает сбор с сообщением.

K предоставляет точную временную метку. В обычном DOM A есть только день и время: экспорт сохраняет `ts: 0`, распознанный день либо исходную подпись даты. Проверяются русский, английский и язык браузера/страницы. Для каналов ссылка `source_url` строится из числового маршрута чата и серверного ID сообщения; для нераспознанных маршрутов и обычных групп она `null`. Ссылки внутри поста сохраняются в `links`. Признак пересылки из DOM не подтверждает авторство и не определяет, чьи цитаты приведены внутри поста.

Селекторы A сверены с [официальным исходником Telegram Web A](https://github.com/Ajaxy/telegram-tt/tree/28ffcf710b15571e5a2f7bb3bdce3fc90fc8ec80/src/components/middle). Обычный текст A уже целиком находится в DOM; в K расширение нажимает известные кнопки разворачивания. Внутренние API Telegram и хранилища аккаунтов/сессий не используются.

Проверки на настоящем браузерном DOM находятся в `tests/dom.test.js`: при доступном для Node Playwright запусти `node --test tests/dom.test.js`. Переменная `TGE_BROWSER_EXECUTABLE` задаёт путь к Chromium. Фикстуры проверяют K/A и сбор истории, но не заменяют проверку в авторизованной вкладке Telegram.

## FAQ

### Работает ли в каналах с включённым «Запретить сохранение контента»?
Да, именно для этого расширение и сделано.

### Работает ли в десктопном/мобильном Telegram?
Нет. Десктоп и мобильный клиенты рендерят текст в нативном коде, а не в DOM. Открой Telegram **Web** в браузере: `web.telegram.org`.

### Узнает ли админ канала, что я скопировал пост?
Нет. Всё происходит локально. Сетевых запросов расширение не делает — это можно проверить в DevTools → Network.

### Можно ли скачать фото / видео / голосовые?
Нет, расширение работает только с текстом.

### Это нарушает ToS Telegram?
Расширение не обращается к API Telegram. Оно читает DOM страницы, которая уже загружена в твоём браузере — те же данные, которые видят твои глаза. При этом автор канала специально просил не распространять его контент — уважай это. Инструмент предназначен для личного использования: заметок, архивации, доступности.
